# Harmonic Pair Synthesizer

[English](README.md) · [简体中文](README.zh-CN.md)

一个运行在浏览器中的双音加法合成器，用于观察、聆听和比较两个音的基频、泛音及其相互关系。可以直接编辑音色、调节频率比，并保存可复现的听觉实验。

使用 HTML、CSS、JavaScript、SVG 和 Web Audio API 实现，无第三方运行依赖、后端或构建步骤。应用界面为英文，便于演示与交流。

## 主要功能

- 在共享频率轴上比较 Tone A（橙色）和 Tone B（蓝色）。横线颜色深浅表示幅值，加粗表示选中。
- 支持对数与线性频率轴，以及频率、音名或二者同时显示。主视图可以缩放、平移，并与 Playback 面板一起调节高度。
- 两个音的基频范围为 C0–C10，约 16.35–16,744.04 Hz。拖动某根泛音线时，会按整数倍率关系整体移动该音的泛音列。
- 支持分数、十进制比值和有正负号的 cents（音分）编辑。Fix ratio 可联动两音的基频，Shift 可细调。
- 支持半音吸附与泛音对齐吸附，虚线连接实际频率重合且幅值非零的泛音。
- 使用可拖动柱状图编辑 1–32 个分量的幅值比例。预设包括正弦波、均匀幅值、反比 1/n（锯齿波）、反平方、三角波和方波。
- 支持参考幅值与整体 RMS 两种音量模式、A/B 音量联动，以及混合双耳或 A 左/B 右声道路由。

## 快速使用

打开发布后的 GitHub Pages 网站，点击 Play 或使用播放快捷键启动音频。建议从较低输出音量开始。

本地运行时，可使用 Python 3 提供静态 HTTP 服务：

```sh
python3 -m http.server 8000 --directory dist
```

然后打开 <http://localhost:8000>。应用使用 JavaScript 模块，请通过 HTTP 服务运行，不要直接双击 `index.html`。

## 快捷键与交互

| 操作 | 功能 |
| --- | --- |
| `Z` / `/` | 播放或停止 Tone A / Tone B |
| `Space` | 播放两个音；已有任一音播放时停止全部 |
| `Esc` | 停止全部 |
| `B` | 切换混合与分离声道路由 |
| `Cmd+S` / `Ctrl+S` | 保存当前实验记录 |
| `Cmd+N` / `Ctrl+N` | 新建默认实验；有未保存修改时提示 |
| `Shift` + 支持的拖动操作 | 细调 |
| 主视图上滚轮 | 缩放频率视图 |
| 拖动主视图背景 | 平移频率视图 |
| 拖动泛音横线 | 调整该音整个泛音列的频率 |
| 双击上下两面板之间的拖动条 | 自动适配 Playback 所需高度 |

点击频率比分数的分子、分母或 cents 数值进入编辑，回车或失去焦点后提交，Escape 取消。左右拖动十进制 B/A 比值可调节频率比。按下点位于整根柱的灰色或有色区域时可调节幅值；点击外围留白或泛音编号仅高亮。点击其他位置取消高亮。

编辑数字、操作选择器或拖动滑动条时，播放快捷键仍有效；输入记录名称时会暂停字母快捷键。部分环境中的浏览器保留快捷键可能优先响应。

## 实验记录与跨设备同步

记录包含音高、音色、声道、调音和视图设置，加载时始终停止播放。只有点击 Save 或按保存快捷键才会保存修改。切换记录或离开页面时会在浏览器允许的情况下提示未保存修改。启动时加载最近打开的已保存记录。

点击侧边栏的 **Export records**，下载包含全部已保存记录及当前设置的 JSON 文件。当前尚未保存的修改也会包含在导出文件中，但导出不会把本机记录标记为已保存。

将文件传到另一台设备，然后点击 **Import records** 导入。导入会合并本机记录，跳过名称和设置完全相同的记录；如果 ID 相同但内容不同，会保留为独立副本。当前打开的设置及未保存修改不会被覆盖。重复导入同一文件不会反复新增副本。单次支持最多 1,000 条记录，文件大小不超过 10 MB。

数据存储在当前浏览器、当前网站来源的本地存储中，没有账号云同步或自动跨设备同步。GitHub Pages 与之前的 Harmonic Lens 网站使用独立存储；迁移时需在旧网站导出，再到新网站导入。旧版 Harmonic Lens JSON 导出文件保持兼容。清除浏览器数据会删除本地记录，建议保留导出备份。

## 合成方式与解释范围

每个音采用有限泛音列进行加法合成：

```text
x(t) = A × sum(r_n × cos(2π n f0 t + φ_n)),  n = 1 … N
r_n = A_n / A
```

参考幅值模式控制 `A`；基音自身的比例 `r_1` 也可编辑。整体音量模式根据实际参与输出的分量进行 RMS 能量归一化，便于在相近电平下比较不同音色。相同 RMS 不保证相同主观响度。输出保护可能统一降低增益，避免合成信号超出范围。

相位自动设置，并使用预设对应的相位符号。当前仅编辑整数倍泛音的幅值比例，不提供独立分量频率或相位编辑。达到或超过音频设备奈奎斯特频率的分量不发声；极高基频下，基音本身也可能超过输出范围。

泛音对齐吸附在 10 cents 内进入，超过 16 cents 释放，优先考虑较低阶且较强的有效泛音。对齐附近优先采用泛音吸附；Fix ratio 开启时暂停该吸附。虚线表示频率重合，不是通用的和谐度或不协和度评分。音名采用十二平均律，A4 = 440 Hz。

触摸操作抑制意外双指缩放和普通文本选择，同时保留页面滚动与文本框编辑。浏览器的辅助功能设置仍可能覆盖部分限制。

## 开发与测试

使用 Node.js 22 或更新版本运行无依赖测试：

```sh
npm test
npm run check
```

应用本身只需要现代浏览器，不需要 Node.js。测试覆盖设置、联动调音、泛音对齐、交互几何、记录保存和记录传输。

| 路径 | 用途 |
| --- | --- |
| `dist/index.html`、`dist/style.css` | 界面与样式 |
| `dist/app.js` | 交互、Web Audio 与实验记录管理 |
| `dist/math.mjs` | 频率、音高、波形与电平计算 |
| `dist/settings.mjs` | 默认值与设置校验 |
| `dist/alignment.mjs` | 泛音匹配与吸附 |
| `dist/records.mjs` | 记录快照、导入导出与合并 |
| `dist/interactions.mjs` | 命中判断、分数与提示框位置 |
| `tests/` | Node.js 回归测试 |
| `.github/workflows/pages.yml` | 检查与 GitHub Pages 自动部署 |

`dist/` 是直接维护的应用源码，并非自动生成目录。资源使用相对路径，可部署在项目级 GitHub Pages 子路径下。为兼容已有数据，保留旧版本地存储键和导出格式标识。

## 部署到 GitHub Pages

创建名为 `harmonic-pair-synthesizer` 的仓库，将这些文件推送到 `main` 分支。在 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。内置工作流会先测试，再仅发布 `dist/`。推送到 `main` 或手动运行会部署；Pull Request 只执行检查。

实际 Pages 地址由工作流部署结果返回。不需要额外 API Key 或仓库 Secret。配置依据：[GitHub Pages 自定义工作流官方文档](https://docs.github.com/zh/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
